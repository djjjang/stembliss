# STEMBLISS - Luxury Medical Concierge

STEMBLISS is an elite cross-border medical concierge web application connecting global patients with South Korea's premier medical institutions for advanced stem cell therapy, anti-aging, and functional medicine.

## Key Features

- **Cross-Border Concierge Architecture**: Complete patient journey overview from pre-travel genomic evaluation to in-hospital cell therapy, translation, and long-term remote follow-up.
- **Clinical Governance & Leadership**: Official credentials and profile of Representative Medical Director Dr. Sanguk Park, MD (Seoul National University College of Medicine), with an interactive high-resolution photo detail modal.
- **Bilingual Interface**: Full Korean (KR) and English (EN) language switching.
- **Interactive Patient Journey**: 6-step medical tourism process roadmap, clinical safety standards, and VIP support tiers.
- **Consultation & Regulatory Modals**: Direct confidential inquiry booking modal and legal compliance disclaimers adhering to Korean Ministry of Health and Welfare regulations.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Motion

## Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install
```

### Development

```bash
# Run local development server
npm run dev
```

The application will be available at `http://localhost:3000`.

### Production Build

```bash
# Compile and build for production
npm run build
```

The compiled assets will be placed in the `dist/` directory.

### Linting

```bash
npm run lint
```
